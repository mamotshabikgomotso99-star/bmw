# BMW Motors — frontend concept

A responsive React + TypeScript showcase built with Vite, Tailwind CSS, Framer Motion, and Lucide.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Media and specification notes

- The hero uses a local copy of [Pexels video 28545709](https://www.pexels.com/video/a-red-car-is-drifting-on-the-track-28545709/) by Videas, listed by Pexels as free to use under its [license](https://www.pexels.com/license/). It shows a red classic BMW drifting at a public event, but the exact model and variant are not verified; it is not claimed to be the exact 1991 BMW E30 325i Sport in the reference image. The supplied [Manor Park Classics photo](https://manorparkclassics.com/auction/lot/lot-160---1991-bmw-325i-sport/?lot=2149&sd=1) remains the poster/fallback reference. The MP4 autoplays muted and loops where browser policy permits, with playback controls and an external source link.
- The showroom is a searchable, filterable guide to major BMW model families across passenger cars, SAVs, electric models, and BMW M. It is not an exhaustive list of every trim, engine, special edition, or vehicle sold in every country. Some families may be discontinued, announced, or available only in selected markets; availability changes by market and model year. Use the official [BMW South Africa model catalogue](https://www.bmw.co.za/en/all-models.html), [BMW global model overview](https://www.bmw.com/en/all-models.html), or a local retailer for current offers.
- Showroom photos are illustrative Pexels vehicle photography, not a verified image match for every listed model. The interface labels these images accordingly.
- Contact and location links route to the official [BMW South Africa retailer locator](https://www.bmw.co.za/en/fastlane/bmw-retailer-locator.html) and [BMW Group international contact page](https://www.bmwgroup.com/en/general/contact.html), where market-specific locations and contact details can be checked.
- Vehicle photography is served from Pexels. A bundled local illustration is used if an image cannot load.
- Typography uses Inter and Inter Tight for a clean, contemporary automotive presentation.
- X3 figures describe the **2026 BMW X3 30 xDrive, U.S. market**. Confirm equipment, fuel economy, and final specifications against the vehicle's market-specific window sticker and the [official BMW USA X3 page](https://www.bmwusa.com/vehicles/x-series/x3/bmw-x3.html).
- This is an independent frontend concept and is not affiliated with or endorsed by BMW AG. Form submission is simulated in the browser; it does not transmit information.
