# BMW Motors

A cinematic, responsive BMW-inspired frontend concept built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Lucide.

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Create a production build with `npm run build`.

## Hero media

The hero plays a licensed Pexels clip of a red classic BMW drifting at a public event. The clip's exact model and event location are unverified, so it is not represented as the exact 1991 E30 325i Sport shown in the reference image. The supplied red E30 photo is used as the poster and video fallback. See [frontend/README.md](./frontend/README.md) for media, specification, and market availability notes.

This is an independent frontend concept and is not affiliated with or endorsed by BMW AG. The contact form is simulated and does not transmit information.
